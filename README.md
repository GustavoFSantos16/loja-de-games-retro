# 🎮 Mini Desafio HTML - GameZone Retro

Projeto desenvolvido como parte do **Mini Desafio HTML**, com o objetivo de criar uma página promocional funcional para a loja **GameZone Retro** utilizando HTML puro em no máximo 50 linhas de código.

---

## 📌 Sobre o Projeto

A **GameZone Retro** é uma página promocional compacta focada na apresentação de jogos e consoles clássicos. O projeto foi construído priorizando a concisão do código, a estrutura válida do HTML e o cumprimento de todos os requisitos essenciais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Sem bibliotecas ou frameworks externos)
- **Inline CSS** (Apenas estilização mínima exigida no HTML)

---

## ✅ Requisitos Cumpridos

- [x] **Limite de Linhas:** Implementado em **48 linhas** (menos de 50 linhas).
- [x] **Estrutura básica:** Título e parágrafos com formatadores `<strong>` e `<em>`.
- [x] **Lista:** Lista não ordenada (`<ul>`) apresentando os consoles disponíveis.
- [x] **Navegação:** 
  - Link interno (âncora) levando à seção de preços (`#tabela_de_preco`).
  - Link externo apontando para uma página externa (aberto em nova guia).
- [x] **Imagem:** Inclusão de imagem promocional temática (`<img src="asset/retro.jpg">`).
- [x] **Tabela:** Tabela formatada com 3 produtos/preços e cabeçalho customizado.
